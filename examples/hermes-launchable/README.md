# NemoClaw Hermes Brev Launchable

This example includes a Notebook for a [Brev launchable](https://brev.nvidia.com).

The notebook takes you from a fresh Brev machine to a working NemoClaw-managed Hermes sandbox. The notebook installs the host prerequisites, prompts for an NVIDIA Build API key, runs Hermes onboarding, verifies the Hermes API, and shows how to open the Hermes TUI and manage policies with the OpenShell terminal.
